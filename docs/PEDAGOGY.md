# Pedagogy

The course uses retrieval practice, incremental labs and teach-backs. Learners maintain one running Azure DevOps project so that identity, Boards, Repos, Pipelines, packages and deployment evidence become connected rather than isolated demonstrations.

Copilot is used to accelerate explanation and drafting. Learners must challenge its assumptions, run commands, inspect results and preserve evidence. A plausible answer without validation does not count as completion.
